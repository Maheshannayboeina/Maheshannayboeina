# Assets

Original SVG artwork built for the ETH3REAL profile.

| File | Purpose |
| :-- | :-- |
| `hero.svg` | Animated Night City personnel-file banner |
| `savefile.svg` | Stats strip: HTB, THM, CVE, CGPA |
| `loadout.svg` | Animated skill bars and toolbelt |
| `divider.svg` | Animated section divider |
| `footer.svg` | Closing neon sign |
| `social-preview.svg` | Source for the 1280×640 social card |
| `social-preview.png` | Upload-ready social preview |

Display type is [Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch) (SIL Open Font License), converted to outlines so the artwork renders identically on every machine. All other type uses the system monospace stack.
